# 硬件启动记录 · 2026-09-28

已在实际板卡确认：

- 芯片：ESP32-S3 revision v0.2，内置 8 MB PSRAM；外部 Flash 16 MB。
- 当前连接经 FT232R USB UART。不是原生 USB HID 数据通道。
- 921600 / 460800 读取出现损坏数据，115200 稳定。
- 刷写前备份前 2 MiB（启动、分区表及本次固件写入范围），仅本地保存，不是完整 16 MiB 备份。
- 固件构建通过，写入后哈希校验通过。
- 串口确认固件启动并广播，Mac 应用扫描到 KeyboardBridge-S3。
- 配对窗口可通过本地串口开启；六位配对码不写入仓库。

- 用户已完成系统六位码配对，Mac 应用确认收到协议响应。
- 已实测手动断开后重连，应用再次收到协议响应。
