# Keyboard Bridge BLE v1

Mac 是 Core Bluetooth central，ESP32-S3 是 BLE peripheral，Windows 只见 USB HID 键盘。无需 Wi-Fi、IP 或路由器。当前仓库实现 Mac 客户端与离线协议测试，**尚无 ESP32 固件，未完成真实 BLE/USB 联调**。

## GATT

- 广播服务 UUID：`77E10001-4B42-4D41-8B52-494447453031`
- INPUT：`77E10002-4B42-4D41-8B52-494447453031`，Write with response。
- ACK：`77E10003-4B42-4D41-8B52-494447453031`，Notify。
- 建议设备名 `KeyboardBridge-XXXX`。名称仅供显示，不是身份认证依据。

固件必须要求加密后才允许 INPUT 写入和 ACK 订阅/通知，并启用 LE Secure Connections 和 bonding。未绑定设备仅可在用户按物理按钮开启的短暂配对窗口内绑定；正常模式只允许已绑定的 central 控制。首次配对的身份验证方式须在固件阶段确定，不能把 Just Works 当作抗中间人认证。Mac 的 Core Bluetooth 会响应外设安全要求，Mac UI 不自行读取或保存蓝牙链路密钥。

客户端保存 Core Bluetooth peripheral UUID，以便重连；这只是设备记忆，**不是加密绑定本身，也不能证明第三方固件强制加密**。固件实现与安全联调前不要转发敏感输入。“忘记设备”清除应用内记忆，系统及板端 bond 需分别清除。

## 20 字节格式

固定 20 字节，适用于默认 ATT MTU 23，不需要分片。

| Offset | 字节数 | 内容 |
|---|---:|---|
| 0 | 1 | 版本 `1` |
| 1 | 1 | 类型：`1` INPUT，`2` ACK |
| 2 | 4 | session，UInt32 little-endian，每条 BLE 连接重新随机生成 |
| 6 | 4 | sequence，UInt32 little-endian，从 1 递增 |
| 10 | 1 | enabled：0/1 |
| 11 | 1 | USB HID 修饰键位图 |
| 12 | 6 | 6 个 USB HID usage，未使用位置补 0 |
| 18 | 2 | 保留，必须为 0 |

普通 usage 排序并去重；超过 6 个普通键时输出六个 `0x01`（USB ErrorRollOver），修饰键不占这六个槽。enabled=0 强制 modifiers=0、keys 全零。此版本为 6KRO，不是 NKRO。

ACK 必须精确回显对应 INPUT 的 session、sequence 和键盘状态，仅类型改成 2。固件应在对应状态已提交到 USB 输出后发送 ACK；ATT 写入成功不能替代应用层 ACK。禁用状态的握手 ACK 可在 USB 尚未枚举时返回，但 enabled=1 时不得在 USB 不可用时虚假确认。

连接后第一包必须是 enabled=0 的释放状态，由此建立 session 并清除残留按键；固件每条连接只接受这个 session 与递增 sequence。新连接须重新建立 session，不接受连接中途更换。会话 ID 只用于关联/防止旧回包误匹配，不是密码或完整抗重放认证。序号不得回绕，达到上限后重连。

## 发送顺序与恢复

- 每次按键状态变化立即排队，按 FIFO 顺序发送，保留短促按下/松开边沿。
- 最多一个 INPUT 在途；同时收到 ATT 写入回调和匹配 ACK 才发下一包，两个回调先后顺序均可。
- 每 50 ms 在空闲时发送当前状态作为心跳；不会把重复心跳堆进在途队列。
- 停止转发时丢弃未发送的旧输入，优先排入全释放状态；在途状态之后必须马上释放。
- 队列上限 32，溢出或已确认连接的在途包超过 500 ms 时断开、返回 Mac。首次配对/握手允许最多 30 秒，期间不能转发输入。
- 固件必须在 BLE 断开时立即释放所有键，在 300 ms 没有收到合法状态时释放并禁用输入。超时后应断开 BLE 连接，以免迟到的旧输入恢复按住状态。
- 自动重连每次等待 3 秒，只连接用户选中/记住的设备；恢复后保持 Mac 模式，用户再次切换才转发。
- 退出或手动断开会尽力发送释放；不能假设最后一包必达，固件断线/看门狗释放是必要条件。

## 验证

`./scripts/test.sh` 包含字节序、20 字节长度、畸形包、会话隔离、旧 ACK 拒绝、双确认先后顺序、短按边沿顺序、队列上限、优先释放和 6KRO 溢出测试。

硬件到货后必须验证：首次配对及拒绝配对、重启重连、蓝牙开关、接收器拔出、Mac 休眠、快速短按/长按/组合键、USB 未枚举/断开、错误固件、真实加密与 bond 权限，以及输入到 USB 输出的延迟分布。不能以单元测试通过替代这些验证。
